This site is a static build: Hugo turns Markdown and a handful of YAML files into plain HTML, the fonts are self-hosted, and there is no JavaScript on the page. It deploys from a Git push to free static hosting.

The reasoning is the same one I apply to production systems: prefer the simplest architecture that meets the requirement. A personal site with a blog needs fast pages, good metadata, an RSS feed and a low-friction way to publish — none of which needs a framework runtime.
